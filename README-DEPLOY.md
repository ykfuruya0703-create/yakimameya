# 焙煎ノート LP サイト一式（デプロイ手引き）

eMplex PBM のサイト構成（トップLP＋コラム一覧＋記事別ページ＋sitemap/robots）に合わせて作成した、焙煎ノートの静的サイトです。
このフォルダの中身をそのままドメイン直下に置けば動きます。

## 中身
- `index.html` … LP（トップページ）
- `column/index.html` … コラム一覧ページ（全12本）
- `column/{slug}/index.html` … 記事ごとの独立ページ（canonical・OGP・Article構造化データ設定済み）
- `assets/base.css` / `assets/article.css` … 共通スタイル
- `images/` … 店頭・店主・豆・焙煎機・ロゴ
- `audio/ep07-watanabe-interview.m4a` … ポッドキャストEP.07の音声（約29MB）
- `sitemap.xml` / `robots.txt`

## 会員登録フォームを動作確認する方法
`index.html` をダブルクリックで開いた状態（`file://`）では、FormSubmitの仕様で送信できません（画面に理由と、メールソフトで登録するリンクを表示します）。次のいずれかで確認してください。
- **ローカルで確認**: `python3 tools/serve.py` を実行すると `http://localhost:8000/` が開きます。ここから送信できます。
- **公開して確認**: GitHub Pagesなどにデプロイした公開URLから送信します。
どちらも、初回は `ykfuruya0703@gmail.com` に届くFormSubmitの有効化メールのリンクをクリックする必要があります。

## ローカルでの確認
内部リンクはすべて `index.html` まで明記しているので、`index.html` をダブルクリックで開いてそのまま確認できます
（フォルダ指定だけのリンクは file:// では開けないため）。
※ 見出し・本文フォント（Shippori Mincho B1 / Zen Kaku Gothic New）はGoogle Fontsから読み込みます。オフライン時はHiragino明朝・游明朝などに切り替わります。

## 公開前に必ず確認・修正する点
1. **ドメインの置き換え**（canonical / og:url / sitemap / robots / 構造化データ）
   ```
   grep -rl "https://YOUR-DOMAIN.example" . | xargs sed -i 's#https://YOUR-DOMAIN.example#https://実際のドメイン#g'
   ```
2. **会員登録フォーム（メール転送）**
   送信内容は FormSubmit 経由で `ykfuruya0703@gmail.com` に転送されます（設定済み）。
   **初回のみ有効化が必要です**: 公開したページから最初のテスト送信を1回行うと、上記アドレスに確認メールが届くので、その中のリンクを1回クリックしてください。それ以降は、登録のたびにメールが届きます（届かない場合は迷惑メールフォルダも確認）。
   送信先を変えるときは `tools/build.py` の `FORM_ENDPOINT` を書き換えて `python3 build.py` を実行します。
   **メールが届かないとき**: (1) 必ず公開URL（https）のページから送信する（`index.html` を直接開いた状態は不可）、(2) `ykfuruya0703@gmail.com` の受信トレイ・迷惑メール・プロモーションタブで、FormSubmitからの「Activate Form」メールを探して有効化する、(3) 有効化後にもう一度送信する。有効化前はフォームに理由が表示されます。
   ※ フォームはWebサーバー上（GitHub Pagesなど）で動作します。`index.html` をファイルとして直接開いた状態では送信できないことがあります。
   ※ 送信先アドレスはHTML内に含まれるため、スパム対策としてハニーポットを入れています。有効化後にFormSubmitが発行する「ランダムなアドレス」に切り替えると、メールアドレスを伏せられます。
3. **ポッドキャストの収録時間**
   元データ（data.js）ではEP.07が「18分」ですが、添付の音声ファイルの実測は約15分18秒でした。LPには「約15分」と表示しています。
4. **OGP画像**
   LPは `images/storefront.jpg` をog:imageにしています。SNS共有用に1200×630pxの専用画像を用意する場合は差し替えてください。
5. **画像の解像度**
   `glossy-beans.jpg`（362×290）・`roasting-drum.jpg`（275×183）・ロゴ（218×132）は小さいため、原寸〜小さめ表示にしています。大きく使うなら高解像度版に差し替えてください。

## コラム本文（長文版）について
各コラムは `tools/columns/{id}.txt` に本文を置いています（1本あたり約3,600〜4,000字）。
- 書式: 先頭行 `kw:` にSEOキーワード、`> ` が「この記事の要点」、`## ` が見出し（目次を自動生成）、`### ` が小見出し、`- ` が箇条書き、それ以外の行は1行＝1段落
- `## よくある質問` 内の `### 質問` ＋ 回答は、FAQPage構造化データとして自動出力されます
- 本文中の `コラム「タイトル」` は、他コラムへの内部リンクに自動変換されます
- 読了時間は文字数から自動計算（約500字/分）
- 文体は「先に結論を置く構成（検索意図に合わせた効率）」と「言い直し・脱線・体感の描写（人の温度感）」を混ぜています。店主・渡部さんの記事は、元データにある事実のみを使用しています

## コラム・ポッドキャストを更新するには
`tools/data.json`（元のdata.jsから書き出したコラム12本・ポッドキャスト8回）を編集し、次を実行すると `site/` のHTML・sitemapが再生成されます。
```
cd tools
python3 build.py
```
`build.py` 冒頭の `DOMAIN` と `FORM_ENDPOINT` を書き換えておくと、再生成のたびに手動置換が不要になります。
（画像・音声は `site/images` `site/audio` に手動で置きます。）

## 補足
- 管理画面（admin.html）と localStorage 連携は含めていません。このLPは静的HTMLで、コラム内容は生成時に埋め込まれます。
- スラッグは元データのIDを流用しています（例: `column/direct-fire/index.html`）。変更する場合は `data.json` の `id` を書き換えて再生成してください。

## 焙煎中の音（ポッドキャスト欄）
`audio/roast-drum.mp3`（回転・火の音）、`roast-1st-crack.mp3`（1ハゼ）、`roast-2nd-crack.mp3`（2ハゼ）は、特徴を再現した**合成のイメージ音**です（画面上の注記は削除済み）。
店の焙煎機で録音した音源がある場合は、同じファイル名で `audio/` に置くだけで差し替わります。
## 焙煎ASMR（`#asmr` セクション）
`audio/roast-asmr.mp3`（約8分・ステレオ・約5.8MB）は、投入→黄変→1ハゼ→発達→2ハゼ→排出・冷却の一釜を通して聴ける**合成のイメージ音**です。
工程ボタン／タイムラインでの頭出し、ループ再生に対応しています。実際の焙煎機で録音したステレオ音源がある場合は、同名で置き換えてください。
その際、工程の開始秒数を変える場合は `tools/build.py` 内の `CH`（0 / 45 / 190 / 300 / 380 / 450 秒）を、音源に合わせて修正してください。

## ラインアップ（ヤキマメヤブレンド／ブラジル／コスタリカ）
`tools/build.py` 冒頭の `PRODUCTS` で管理しています。現在は商品の詳細情報がないため、名称・産地の一般的な傾向・オンラインストアへのリンクのみ表示しています。
`price`（価格）、`roast`（焙煎度）、`desc`（説明）、`url`（商品ページURL）を入れて `python3 build.py` を実行すると、カードに反映されます。商品を増やす場合は、同じ形式で行を追加してください。
